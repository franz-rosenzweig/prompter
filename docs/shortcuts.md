# Shortcuts and the menu bar

## Shortcuts from any app

These work wherever you are, so you never have to find a window mid-call. ⌃⌥P works any time. The rest only work
while the prompter is showing, so they don't get in the way for the rest of the day.

| Keys | Does |
|---|---|
| ⌃⌥P | Show or hide the prompter (with the last script you showed) |
| ⌃⌥Space | Play / pause |
| ⌃⌥= | Faster |
| ⌃⌥− | Slower |
| ⌃⌥] | Next cue |
| ⌃⌥[ | Previous cue |
| ⌃⌥R | Back to the start |
| ⌃⌥M | Next mode |

⌃ is Control and ⌥ is Option. Settings › Shortcuts lists them too. They can't be changed yet, so if one clashes
with another app's shortcut, open an issue.

One clash to know about: if you have more than one keyboard language, macOS can use ⌃⌥Space to switch to the next
one. That's System Settings › Keyboard › Keyboard Shortcuts › Input Sources, and it's off unless you turned it on.
If it's on, turn one of the two off.

## The menu bar

The quote-mark icon at the top right of the screen has:

- **Show Prompter** or **Hide Prompter**
- **Play** or **Pause**, and **Back to Start**, while it's showing
- **Cues**, with a tick next to the one you're in. Pick one to jump there.
- **Mode**: Follow, Voice or Steady
- the reason, if something is stopping it from listening
- **Scripts**: all of them. Pick one to show it.
- **Open Scripts…**, **Settings…** and **Quit Prompter**

## With the mouse

Hover over the prompter to pause it and bring up its bar, click it to pause or play, and scroll to move through the
script. [The prompter](the-prompter.md) has the bar's buttons.

## In the scripts window

⌘N makes a new script, and ⌘Return starts or hides the one you're on. The **Prompter** menu at the top of the screen
has every command from the table above, with its shortcut.
